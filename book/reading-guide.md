# 如何阅读本书

本书适合有 Java 和 Spring Boot 开发经验的读者。第一篇建立服务边界并走通调用；第二篇处理模型交互；随后进入企业 RAG、客户咨询、受控 Agent，最后补齐治理与迁移实验。

初次阅读建议沿业务链顺序推进。已有 RAG 项目的读者可以先读第三篇，再回查身份和调用边界；涉及写操作的项目应重点阅读第五篇的风险、确认、幂等和审计。第七篇的框架与协议实验可按需要选择。

全书保留 01—52 的课程编号。阅读理论和工程判断不要求先启动系统。需要复现时，按书末章节与资源索引选择学习阶段：01—03 对应阶段一，04—12 对应阶段二，后续阶段的范围以索引和项目说明为准。

书中代码保留原有包名、接口和路径。表格、图示和主要代码清单按章编号；网页中的配套链接集中整理为章末资源。演示数据与测试结果有各自适用环境，迁移到实际业务时需要重新验证。

PDF 使用 A4 版式，较密的宽图独立横排，适合固定版式阅读与打印，EPUB 可随设备调整字号。两种版本均包含完整正文和配图，不依赖联网加载图片；外部文档、源码与问题反馈需要联网访问。
