# 验证档案

本目录保存项目各项能力的验证范围、可执行命令、已检查行为和未覆盖的外部条件。文件名中的数字用于保持历史链接稳定，不表示使用前必须按顺序阅读。

## 报告类型

- **确定性回归**：记录业务规则、接口契约、错误映射和失败分支，默认不访问外部系统。
- **外部集成**：验证 PostgreSQL/pgvector、身份平台或远程协议等真实基础设施，必须明确目标环境和安全边界。
- **真实模型运行**：保留执行时间、模型、Prompt、数据集、代码 tag、Token、延迟和失败样例。
- **综合能力摘要**：汇总一组关联能力的已覆盖范围和生产替换项。

## 正确理解验证结果

单元测试通过只能说明当前代码对稳定输入保持了预期行为。它不能代替真实 Provider、数据库、身份、下游回执、容量和故障恢复验证。

真实运行报告与当时的代码 tag、数据集、Prompt、模型和环境绑定。任何一项变更后，需要重新运行才能得出当前结论，不能事后修改历史报告冒充新结果。

## 安全与追溯

- 报告可以记录公开 tag 或在公开仓库可解析的完整 Commit SHA。
- 不记录父工作区、私有仓库或已被重写历史中的提交。
- 不写入 API Key、Bearer Token、Provider 私有地址、用户数据和未脱敏模型输出。
- 除非两份报告绑定同一代码、数据集、Prompt、模型与环境，否则不能将它们解读为严格效果对比。

新增或修改报告时，同步更新生成脚本与回归测试，避免手工结论与可执行结果分离。
